# Coding Standards

- TypeScript strict mode is mandatory; never use `any`.
- Use functional React components and composition. Keep components focused and reusable.
- Use Tailwind utilities and documented design tokens; do not use inline style objects for layout or visual styling.
- Prefer semantic HTML. Buttons perform actions; links navigate.
- Validate all external data when backend integrations are introduced.
- Avoid duplicated strings and logic. Keep page content in typed, maintainable content modules.
- Add tests for new logic and meaningful interactive behaviour.
- Keep ESLint and Prettier clean.
- Do not use misleading claims or placeholder business facts in production-facing copy.
